## English (en-US)

**Short description** (max. 80)

View, edit and create JSON files. Readable, offline, no ads, no tracking.

**Full description**

JSON Viewer opens .json files from your file manager, mail or any other app and
shows them the way a person reads them: objects become sections with headings,
lists of records become tables, yes/no values get check marks, colors a swatch
and dates a readable format.

Three tabs, one tap apart:
• View – the document, rendered and easy to read
• Form – change values, add fields and list items without typing any JSON syntax;
  new list entries take over the fields of the previous one
• Text – the raw file with syntax highlighting, live error checking (line and
  column), Format/Minify and code folding like in a code editor

On tablets and in landscape, split view shows the text next to the rendered view.

Also: tree view with search, copy any value or its path, paste JSON from the
clipboard, save back to the original file or "Save as", light and dark theme,
German and English.

No account, no ads, no tracking, no internet permission – your files never leave
your device. Open source: github.com/nicolasasauer/json-viewer

## Deutsch (de-DE)

**Kurzbeschreibung** (max. 80)

JSON-Dateien ansehen, bearbeiten, erstellen. Lesbar, offline, ohne Werbung.

**Ausführliche Beschreibung**

JSON Viewer öffnet .json-Dateien aus dem Dateimanager, der Mail oder jeder anderen
App und zeigt sie so, wie Menschen sie lesen: Objekte werden zu Abschnitten mit
Überschriften, Listen von Datensätzen zu Tabellen, Ja/Nein-Werte bekommen Haken,
Farben ein Farbfeld und Datumswerte ein lesbares Format.

Drei Tabs, einen Tipp entfernt:
• Ansicht – das Dokument, aufbereitet und leicht lesbar
• Formular – Werte ändern, Felder und Listeneinträge hinzufügen, ganz ohne
  JSON-Syntax; neue Einträge übernehmen die Felder des vorherigen
• Text – die Rohdatei mit Syntaxhervorhebung, Fehlerprüfung in Echtzeit (Zeile
  und Spalte), Formatieren/Minimieren und Einklappen wie im Code-Editor

Auf Tablets und im Querformat zeigt die geteilte Ansicht Text und Ansicht
nebeneinander.

Außerdem: Baumansicht mit Suche, Werte oder ihren Pfad kopieren, JSON aus der
Zwischenablage einfügen, zurück in die Originaldatei oder unter neuem Namen
speichern, helles und dunkles Design, Deutsch und Englisch.

Kein Konto, keine Werbung, kein Tracking, keine Internet-Berechtigung – deine
Dateien verlassen nie dein Gerät. Open Source: github.com/nicolasasauer/json-viewer
